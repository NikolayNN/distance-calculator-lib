# История изменений

## Не выпущено

### Сборка

- Сборка возвращена на JDK 11. Байткод `DistanceCalculatorImpl` побайтно совпадает с версией 7.7. Новый тест проверяет MD5 класса при сборке.
- Версия 7.8 была собрана на JDK 25. Исправление `TrackFilter` в ней корректно, но байткод `DistanceCalculatorImpl` отличается от версии 7.7. Потребителям, которые включают этот класс в контрольную сумму, в том числе Aurora, нельзя использовать 7.8.

## 7.8

### Исправления

- При упрощении трека фильтр измеряет расстояние от точки до отрезка.

### Сборка

- Maven-пакеты публикуются в GitHub Packages. Ветка `develop` выпускает snapshot, а релизы из `master` получают тег `v<версия>`.
