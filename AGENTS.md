# Разработка и релизы

Изменения готовятся в `develop`. Версия в `pom.xml` — текущая разрабатываемая версия. Изменения для релиза записываются в раздел `## Не выпущено` в `CHANGELOG.md`.

Проверка перед релизом — `mise exec -- mvn -B verify`. Библиотека должна сохранять совместимость с Java 11. Тесты включают JUnit Jupiter и JUnit 4.

Для выпуска используйте `/aurora-release`. Пакет в GitHub Packages публикует GitHub Actions. CI создаёт тег `v<версия>` после успешной публикации из `master`.
