# Разработка и релизы

Изменения готовятся в `develop`. Версия в `pom.xml` — текущая разрабатываемая версия. Изменения для релиза записываются в раздел `## Не выпущено` в `CHANGELOG.md`.

Собирайте библиотеку на JDK 11. Aurora включает `DistanceCalculatorImpl.class` в метрологическую контрольную сумму, поэтому байткод этого класса должен побайтно совпадать с версией 7.7. Изменение исходника класса или компилятора требует отдельного решения владельца.

Проверка перед релизом — `mise exec -- mvn -B clean verify`. Тесты включают JUnit Jupiter и JUnit 4.

Для выпуска используйте `/aurora-release`. Пакет в GitHub Packages публикует GitHub Actions. CI создаёт тег `v<версия>` после успешной публикации из `master`.
